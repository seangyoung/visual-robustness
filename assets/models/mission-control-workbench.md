# Mission Control Workbench

Version 2.1.1 is generated by `scripts/blender/create_mission_control_workbench.py` for Three.js/WebXR.

The deployable GLB is written to `public/assets/models/mission-control-workbench.glb`.
Vite copies it to `dist/assets/models/` without hashing so the GitHub Pages app
can load it beneath the configured `/visual-robustness/` base path.

## Geometry

The console body, deck, and front trim are continuous swept solids. The five named
control stations are transform anchors only, so there are no overlapping shell
modules or scalloped intersections along the rear edge.

## Addressable screens

| Screen ID | GLB node |
| --- | --- |
| `knob-feedback` | `Screen_Knob` |
| `group-01` | `Screen_Group_01` |
| `group-02` | `Screen_Group_02` |
| `group-03` | `Screen_Group_03` |

Each screen is an independent mesh with its own material. Use
`setScreenTexture()`, `setScreenCanvas()`, or `setScreenColor()` from
`src/scene/missionControlWorkbench.js`.

## Interactive controls

- `knob-main`: push-rotary control, -135 to +135 degrees in 15-degree steps; pressing it resets the stress test.
- `radio-01` through `radio-09`: three mutually exclusive groups of three push buttons.
- `submit`: momentary button with 18 mm travel.
- `guard-cover`: hinged amber safety cover with open and closed states.
- `guarded-secondary`: momentary button that activates only while the guard is open.
- `workbench-grab-handle`: illuminated rail under the front lip used to translate
  the complete workbench in VR. It is intentionally separate from the lesson controls.

The visible stress-test dial is approximately 5 cm across. Its transparent hit
target is larger so a natural thumb-and-index grasp can engage before the fingers
close far enough to emit a formal WebXR pinch event.

Radio group IDs are `radio-group-01`, `radio-group-02`, and `radio-group-03`.
Selecting a button through `activate()` or `setRadioSelected()` depresses it and
returns the other two buttons in its group to their unpressed positions.

Every interactive pivot stores its interaction type, stable control ID, local
motion axis, and applicable limits in glTF extras. Mesh descendants can be
raycast and passed to `activateFromObject()`.
