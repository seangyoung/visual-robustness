# Mission Control Workbench

Generated by `scripts/blender/create_mission_control_workbench.py` for Three.js/WebXR.

## Runtime files

- `mission-control-workbench.glb`: optimized runtime asset with named nodes and glTF extras.
- `mission-control-workbench.blend`: editable Blender source.
- `mission-control-workbench-preview.png`: reference render.

## Addressable screens

| Screen ID | GLB node |
| --- | --- |
| `knob-feedback` | `Screen_Knob` |
| `group-01` | `Screen_Group_01` |
| `group-02` | `Screen_Group_02` |
| `group-03` | `Screen_Group_03` |

Each screen is an independent mesh with its own material. Use
`setScreenTexture()`, `setScreenCanvas()`, or `setScreenColor()` from
`src/scene/missionControlWorkbench.js`.

## Interactive controls

- `knob-main`: rotary control, -135 to +135 degrees in 15-degree steps.
- `toggle-01` through `toggle-09`: two-position rocker switches.
- `submit`: momentary button with 18 mm travel.
- `guard-cover`: hinged safety cover with open and closed states.
- `guarded-secondary`: momentary button that activates only while the guard is open.

Every interactive pivot has `role: "interactive_control"`, an `interaction`
type, a stable `control_id`, a local motion axis, and its applicable limits in
glTF extras. Mesh descendants can be raycast; pass the intersected object to
`activateFromObject()`.

## Minimal Three.js usage

```js
import { loadMissionControlWorkbench } from "./scene/missionControlWorkbench.js";

const workbench = await loadMissionControlWorkbench({
  onControl(event) {
    if (event.id === "submit") submitCurrentDesign();
  },
});

scene.add(workbench.root);
workbench.root.position.set(0, 0, -2.4);

// Use these meshes in desktop or XR raycasting.
const interactiveMeshes = workbench.getInteractiveMeshes();
const hit = raycaster.intersectObjects(interactiveMeshes, false)[0];
if (hit) workbench.activateFromObject(hit.object);

// In the application's frame loop:
const deltaSeconds = clock.getDelta();
workbench.update(deltaSeconds);

// Each display can receive a separate CanvasTexture.
workbench.setScreenCanvas("knob-feedback", knobCanvas);
workbench.setScreenCanvas("group-01", paletteCanvas);
```

For direct manipulation of the rotary control, call `setKnobNormalized()` while
a controller is held on the knob. For controller-ray selection, `activate()`
naturally steps the knob, flips toggles and the guard, and depresses buttons.
